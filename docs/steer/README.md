These documents define the reusable layer of STEER. Product-specific rules remain with
the project that needs them.

1. [Operating model](OPERATING-MODEL.md)
2. [Adoption and installation](ADOPTION.md)
3. [Reference architecture](REFERENCE-ARCHITECTURE.md)

The normative controls currently live in `steer/operating-system/`, with reusable role
and artifact templates in `steer/agents/` and `steer/templates/`. Project guardrails,
briefs, exams, signals, and reviews are installed alongside each project.
